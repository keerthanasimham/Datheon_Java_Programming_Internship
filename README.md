# Datheon Java Programming Internship

This repository contains four Java programming projects developed as part of my Datheon Java Programming Internship.

## Projects

### 1. Student Grade Management System
- Student registration and grade management.
- GPA calculation and report cards.
- CSV file handling and Java Collections.

### 2. Bank Account and ATM Simulation
- Savings and checking account management.
- Deposits and withdrawals.
- PIN verification and custom exceptions.
- Transaction history and logging.

### 3. Word Counter and Test Corpus Analyzer
- Text file processing using Java IO.
- Total and unique word counting.
- Word frequency analysis.
- Top 10 frequently used words.

### 4. Digital Library Inventory and Checkout Management
- Book catalogue management.
- Member registration and book checkout.
- Book return processing.
- Due-date tracking and overdue fine calculation.

## Technologies Used
- Java (JDK 17+)
- Object-Oriented Programming
- Java Collections Framework
- File Handling
- Exception Handling
- Java Date and Time API
